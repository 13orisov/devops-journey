# Неделя 3: сайт в Docker
## Что сделал
- Собрал свой образ сайта: nginx:alpine + COPY index.html.
Разобрал слои и кэш сборки (CACHED), собрал v1 и v2.
- Порт публикую только на 127.0.0.1: Docker пишет свои
правила в iptables и обходит ufw.
- Bind mount с :ro: правка на хосте видна сразу без
пересборки, а контейнер писать в файл не может
(Read-only file system).
- Логи: docker logs. В логе nginx IP клиента — 172.17.0.1,
адрес моста docker0, а не настоящий. На неделе 4 решу
заголовком X-Real-IP.
- Сеть: мост docker0 172.17.0.1/16, контейнер 172.17.0.2,
сервер ходит в контейнер напрямую.
- Внутри контейнера: PID 1 — nginx master от root, рабочие
процессы — от пользователя nginx.
- Docker Compose: build, ports, restart: unless-stopped.
Проверил, что контейнер поднимается после смерти PID 1.
## Что сломалось и как починил
- `docker buil` → unknown shorthand flag. Опечатка.
- `docker build -t ...` без точки → requires 1 argument.
Точка — папка с Dockerfile, контекст сборки.
- Вставил заглушку 172.17.0.X вместо адреса → пустой
вывод. Флаг -s прячет ошибки curl, теперь пишу -sS.
