- `/etc/letsencrypt` добавлен в ночной бэкап.

## Что сломалось и как починил
- **Тестовый выпуск сертификата падал** с `unauthorized … reader size limit exceeded` на IPv6-адресе. NS Timeweb отдавали для домена скрытую AAAA на свой хостинг — в панели её не было. Let's Encrypt сначала идёт по IPv6, поэтому проверка уходила не на мой сервер. Нашёл через `dig AAAA … @ns1.timeweb.ru`: проверял DNS напрямую у NS, а не по панели. Добавил свою AAAA на IPv6 сервера, написал в поддержку — после исправления выпуск прошёл.
- **`nginx -t` ругался** `"server" directive is not allowed here` — при правке пропало подчёркивание в `server_name`. Поймал до перезагрузки.
- **`scp` на сервер падал** с `dest open … Failure` — каталога сайта ещё не было. Создал через `mkdir -p` и отдал своему пользователю.
- **`chmod` с маской молча не срабатывал** на архивах бэкапа: маску раскрывает моя оболочка до `sudo`, а каталог закрыт правами `700`. Заменил на `find … -exec chmod 600 {} +`.
- **`www` сначала не резолвился** — новая запись ещё не разошлась по DNS. Проверял через `dig`, дождался.
