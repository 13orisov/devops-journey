# DevOps Journey

Публичный журнал моего перехода из техподдержки в DevOps (с фокусом на DevSecOps).
Всё делается руками на собственном VPS: каждая неделя — рабочий результат и заметки о том, что сломалось и как починил.

## Цель
- **Декабрь 2026:** портфолио проектов уровня Junior DevOps
- **I квартал 2027:** оффер на позицию Junior DevOps

## Стенд
- VPS: 2 vCPU, 4 ГБ RAM, 50 ГБ NVMe, Ubuntu 24.04
- Рабочая машина: macOS

## Дорожная карта
