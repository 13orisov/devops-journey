- Первый бан через несколько минут после запуска

### Что сломалось
fail2ban упал после настройки: `option 'bantime' in section 'DEFAULT' already exists`.
Причина: на сервере уже был fail2ban (с 19.08) и jail.local на 988 строк — полная копия jail.conf.
Мой блок добавился к нему, и получились дубли [DEFAULT] и [sshd].
Нашёл через `journalctl -u fail2ban`, проверил `fail2ban-client -t`, сохранил старый файл в .bak,
переписал jail.local начисто (10 строк).
Вывод: в .local держу только изменения; после рестарта проверяю, что сервис реально работает.
